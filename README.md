# VR Website Landing Page

A responsive, multi-section landing page for Virtual Reality products, featuring modern layout design, interactive navigation, features highlight, product catalog, and blog showcases.

## ✨ Features

- **Responsive Design:** Fully fluid and responsive across desktop, tablet, and mobile screens using the Bootstrap grid framework.
- **Fixed Navigation:** Top navbar with quick smooth-scrolling anchors to key sections.
- **Hero Banner:** Eye-catching full-screen cover banner highlighting the main theme.
- **Features Showcase:** Grid overview highlighting core capabilities (Easy to connect, VR capability, Video games, Interaction, etc.).
- **Included VR Kit:** Clean product visual cards detailing headset components and accessories.
- **Feature Deep Dive:** Alternating media-and-text blocks highlighting optics and touch controller details.
- **Trending Blogs:** Card-based blog listing section with smooth call-to-action link vectors.
- **Products Section:** High-impact full-height background cards featuring key products and pricing.
- **Footer:** Complete footer including social icon integration, address, contact details, and dynamic copyright section.
